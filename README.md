# 本地记账

面向个人使用的 HarmonyOS 记账应用，支持手动记账、账单截图识别和通知自动入账。账目与识别规则保存在设备本地，无需注册账号。

运行要求：**HarmonyOS 7 / API 26 及以上**。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 账目与统计 | 新增、编辑和删除收支；设置记账周期，按周期或自选范围查看现金结余、趋势，以及分类、商户和来源统计。 |
| 信用卡记账 | 区分普通账目、信用卡消费与还款；消费计入支出，还款单独统计。支持预览并批量标记历史消费，以及撤销最近一次批量标记。 |
| 截图 OCR 导入 | 初始支持微信支付、支付宝和工商银行账单截图，可从图库选择或由其他应用分享；识别结果经逐笔复核后保存。 |
| 通知自动入账 | 授权后按规则识别交易；初始规则覆盖工商银行、中信银行、支付宝和微信支付。通知历史支持按来源、关键词和日期查询。 |
| 识别规则配置 | 从截图或通知提供样例，确认交易字段，借助外部 AI 生成规则，再在本机预览并保存；高级设置保留手动编辑、启停和排序。 |
| 备份与交换 | JSON 完整备份包含账目、识别规则和记账周期；CSV 用于账目导入导出。恢复或导入前均提供预览与确认。 |

## 开始使用

1. **手动记账**：在“账本”页选择“手动记账”，填写金额、日期、收支和商户等信息。已有账目可编辑，也可调整记账类型。
2. **识别截图**：选择“识别账单截图”，或从其他应用分享图片。核对金额、日期、收支及商户，取消不需要的记录后再保存。来源无法确定时需手动选择；缺少可靠日期的记录不会入账。
3. **通知记账**：进入“通知 → 设置”，打开通知访问授权并选择来源应用。匹配规则且能解析出有效金额、收支和时间的新通知才会自动入账；可在通知历史中检查收到的内容。

### 添加或适配识别规则

1. 在“账本 → 设置 → 管理 OCR 识别规则”选择截图；或在通知详情中选择“用此通知创建规则”。
2. 检查样例原文，确认其中一笔交易的金额、日期和收支，可补充商户、分类。遮盖敏感信息后，复制完整材料交给你使用的外部 AI。
3. 粘贴 AI 返回内容，应用自动校验并展示字段对照。核对通过后确认保存，新规则放在列表顶部优先使用。

应用不会自动向外部 AI 发送数据，样例和预览结果只在当前页面使用。JSON 导入兼容正则字段中的单反斜杠 `\d`、`\s`、`\.` 等写法；已有合法 JSON 转义保持原意。

OCR 识别和通知模板可能变化，单个样例通过不代表覆盖所有交易格式。截图始终需要复核；通知规则修改仅影响之后收到的通知。字段、日期、查重和转义细节见 [OCR 与通知处理规则](docs/ocr-and-notifications.md)。

## 备份与恢复

在“账本 → 设置 → 数据备份”中操作：

| 格式 | 适用场景 | 恢复或导入行为 |
| --- | --- | --- |
| JSON 完整备份 | 保存账目及入账识别信息、OCR/通知规则、记账周期 | 账目按 ID 合并，冲突保留本机；识别规则和记账周期在确认后整体替换。 |
| CSV 账目文件 | 账目交换，或用表格工具查看数据 | 接受本应用导出的格式，预览无效行并跳过与现有账目完全相同的记录；不保存识别规则、周期和入账识别信息。 |

完整备份不包含通知归档、截图或历史批量标记的撤销记录。备份为明文文件，请妥善保管；卸载应用前建议导出 JSON 完整备份。详细范围与合并规则见 [架构与数据流](docs/architecture.md)。

## 数据与隐私

账目、通知归档及识别规则保存在设备本地，OCR 和通知解析也在本机完成，不提供云同步。截图只在识别流程中读取，不作为账目附件保存。通知归档会保存完整标题和正文，可能包含个人或金融信息。

## 开发与安装

- 技术栈：Stage 模型、ArkTS / ArkUI、ArkData、Core Vision Kit。
- 开发环境：DevEco Studio 与 HarmonyOS SDK 26；应用包名为 `com.gyg.harmonyledger`。
- 发布产物见 [Releases](https://github.com/cszdlt/harmonyos-ledger/releases)。自动发布的 HAP 未签名，真机安装需配置本机签名，步骤见 [构建与签名](docs/build-and-signing.md)。

签名配置 `signing.local.json` 仅保存在本机。账目、通知、截图、备份和签名材料均不应提交到仓库。
